Winden Drag & Drop Demo

How to Test Drag & Drop:

  1. Toggle the "Split Screens" checkbox to enable multiple input fields
  2. Add some Tailwind classes to different screens (e.g., "bg-blue-500" to Default, "text-red-500" to md:)
  3. Click and drag a class tag from one screen to another
  4. The class should move from the source screen to the target screen with the appropriate prefix
  5. Visual feedback should show during dragging (opacity change, dashed borders)
